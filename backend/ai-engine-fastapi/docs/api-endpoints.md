# API Endpoints

## Resume Parsing Service
- `GET /health`
- `POST /v1/resume/parse`
- `POST /v1/resume/parse/batch`

## Candidate-Job Matching Service
- `GET /health`
- `POST /v1/matching/score`
- `POST /v1/matching/rank`
- `POST /v1/matching/explain`

## Interview Analysis Service
- `GET /health`
- `POST /v1/interview/analyze`
- `POST /v1/interview/analyze/batch`

## Workforce Analytics Service
- `GET /health`
- `POST /v1/workforce/forecast/hiring-demand`
- `POST /v1/workforce/skill-gap`
- `POST /v1/workforce/productivity-alerts`
