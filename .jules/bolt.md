## 2025-05-18 - Database Aggregation for Loan Service Summary
**Learning:** Calling `findAll()` and performing JavaScript in-memory `.filter()` and `.reduce()` operations to calculate pending loan summary metrics creates unnecessary network overhead and memory allocation as the dataset scales. Replacing array operations with TypeORM `createQueryBuilder` conditional aggregation (`SUM(CASE WHEN loan.status = 'PENDING' ... END)`) computes the exact counts and total amounts directly in the database engine in a single query while enforcing tenant isolation via `TenantQueryPolicy.enforce`.
**Action:** When calculating summary or aggregated metrics in backend services, use `createQueryBuilder` with SQL aggregate functions (`SUM`, `COUNT`) and `TenantQueryPolicy` governance instead of pulling whole entity lists into application memory.
